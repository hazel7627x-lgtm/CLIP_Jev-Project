## 1 我们究竟在研究什么

输入是一张图片和一句话，输出三类关系：E（图片支持）、N（信息不足）、C（图片反驳）。

Teacher有两种：base是Qwen3-VL-4B-Instruct；Jev是同一底座加载公开的任务适配器。我们使用已有Teacher，没有重新训练该适配器。Jev接受过相关任务适配，不能宣传成完全没有相关任务训练的零样本Teacher。

Student是冻结的CLIP编码器加可训练MLP。图文特征为 `[v,t,abs(v-t),v*t]`，不是只计算一次图片与句子的点积。训练只更新分类头，没有微调CLIP编码器，也没有替换其attention。

```text
图片和句子 → 冻结CLIP → 图文特征 → 可训练MLP → E/N/C
                                           ↑
                             gold标签 + Teacher三类软概率
```

CE学生只学习gold；KD学生同时学习gold和Teacher概率。部署时Student自己预测，不需要再次调用Teacher。

最初的问题是“蒸馏能否让学生更好”。经过补实验，现在可以分成五个具体问题：

1. 分类：蒸馏是否超过合理调参的CE与标签平滑？
2. 概率：Teacher校准改善什么，是否优于直接校准学生？
3. 输入：学生是否利用图片，收益是否仅靠文本线索？
4. 能力边界：学生是否保留Teacher的复杂图文配对能力？
5. 实用取舍：学生比Teacher便宜多少，同时损失多少能力？

这是一项对上述问题的实证比较，不是一个已经提出全新CLIP算法的项目。

## 3 为什么看起来一直在重复跑

存在三类不同的操作，不能混为训练次数：

- **新训练**：更新MLP权重，产生新的checkpoint。
- **评价或重放**：固定权重，换一套输入或重算输出，不产生新的训练模型。
- **后温度校准**：固定权重，只拟合一个T，输出概率变化，类别不变。

本次按已归档最佳checkpoint去重，排除resume/state断点副本：第一阶段33个，Stage2 45个，两个集合的文件哈希无重复，共78个。该数量只覆盖本次已核查归档，不把未正式保存的试跑算进来，也不代表78次独立研究或78份独立测试证据。

第一阶段33个 = 基础9个 + 额外α配置12个 + 硬标签／图像／文本消融9个 + base KD 3个。

Stage2 45个 = 核心39个 + 额外探索6个。核心39个为：CE三学习率9个、公共学习率两种LS共6个、Jev KD18个、文本CE/KD6个。额外6个是初轮lr=0.001的LS与KD；初轮CE与学习率比较中的同一checkpoint不能重复计数。

P0、P1测量、Student后校准、统一评价、统计重算没有再增加这些训练模型的数量。

## 4 第一阶段和Stage2是什么关系

两者属于同一项目的两轮开发设置。第一阶段提供初始结果，Stage2加强对照、检查简单替代解释。它们不是两份全新数据上的独立复现。

| 项目 | 第一阶段 | Stage2 |
|---|---|---|
| 数据与冻结CLIP特征 | 既有固定划分和缓存 | 继续复用，经哈希核验 |
| 主要公共学习率 | 0.001 | CE三点搜索后采用0.0003 |
| 主要Jev KD | α=0.75，τ=2 | α=0.75，τ=2 |
| Jev Teacher校准参数 | b=0.85，T约1.414214 | b=0.15，T约1.342573 |
| 简单监督对照 | 主要是CE | 增加两种LS，保留CE学习率搜索 |
| 学生后校准 | 未作为完整主要对照 | CE、LS、原始／校准KD均有固定学生T |
| 输入消融 | 图像CE、文本CE | 文本CE与文本KD，与同设置图文模型比较 |
| base KD | 有，lr=0.001 | 尚无lr=0.0003的匹配模型 |
| 硬标签KD | 有，lr=0.001 | 尚无lr=0.0003的匹配模型 |

**Stage2加强的是实验比较，不是模型成绩全面升级。** 例如历史1000条上的第一阶段CE为59.906%、原始KD为61.140%；Stage2分别为59.156%、60.729%。开发集选出的设置不保证在历史评价集更高，不能事后各挑一个阶段的最好数字凑成主表。

三个温度概念也要分开：Teacher校准T作用于Teacher输出；训练τ=2作用于KD损失；学生后校准T作用于最终Student预测。它们不能混用。

## 6 哪些结果偏正面 哪些不确定 哪些偏负面

### 分类收益有正向均值 但仍未确认稳定优势

| 阶段与集合 | CE Macro-F1 % | 原始KD Macro-F1 % | KD−CE 百分点及95%区间 |
|---|---:|---:|---|
| 第一阶段 历史1000条 | 59.906 | 61.140 | +1.233 [−0.978,+3.339] |
| 第一阶段 补充200条 | 61.172 | 64.113 | +2.942 [−1.700,+7.975] |
| Stage2 历史1000条 | 59.156 | 60.729 | +1.573 [−0.470,+3.672] |
| Stage2 补充200条 | 62.353 | 63.500 | +1.147 [−3.368,+5.592] |

正向的一面是两轮、两套集合的均值方向一致。限制是四个区间都跨0，而且共用评价图片，不能把它们当四次独立成功，也不能把所有模型合成更多种子来缩窄区间。没有确认优越，不等于已经证明无效或等效。

Stage2原始KD对两种LS的分类区间也均跨0。因此“超过了所测LS的均值”可以报告，“收益已证明来自Teacher特定知识”不成立。

### 教师来源在第一阶段有清楚差异

第一阶段原始Jev KD对base KD：历史1000条高约7.575个百分点，区间[4.968,10.202]；补充200条高约14.308个百分点，区间[7.217,20.879]。

这项旧结果有效，因为比较双方都在第一阶段设置下。它支持“这些Teacher提供的监督效果不同”，不能把差异完全归因于推理知识；Teacher准确性、偏向、置信度和任务适配都会一起变化。

本次确认旧base KD学习率为0.001，Stage2为0.0003，因此旧base不能直接拼入Stage2主表。若保留为单独的第一阶段Teacher对照，无需重训；若要在Stage2内比较Teacher来源，才需要新增匹配的3个base学生。

### 校准有实际作用 但主要作用不是提高分类F1

Stage2历史1000条：

| 方案 | Macro-F1 % | NLL | ECE % |
|---|---:|---:|---:|
| 原始KD | 60.729 | 0.908463 | 10.230 |
| 原始KD＋学生后校准 | 60.729 | 0.861393 | 3.438 |
| 校准Teacher后KD | 59.866 | 0.870675 | 5.268 |
| 校准Teacher后KD＋学生后校准 | 59.866 | 0.861816 | 3.160 |

偏正面的证据：原始KD直接做学生后校准，历史1000条上的NLL、ECE、Brier都改善，辅助区间均不跨0。温度由val_fit拟合，没有用本轮评价标签调温度。

偏负面的证据：Teacher校准KD相对原始KD的历史1000条F1低0.863个百分点，辅助区间[−1.552,−0.215]；补充200条也有下降均值，但区间跨0。更好的概率不能写成更好的分类。

关键认识：简单学生后校准可以达到有竞争力的概率结果。两种KD都做学生后校准后，历史1000条的NLL、ECE、Brier差值区间均跨0。不能说Teacher校准全面胜出，也不能说两者已证明等效。

### 图像有贡献 但复杂能力迁移没有得到支持

Stage2历史1000条，图文CE比文本CE高3.259个百分点，辅助区间[0.385,6.037]；图文KD比文本KD高3.799个百分点，区间[1.089,6.550]。支持“输入图片在这套任务和设置下有贡献”。补充200条的对应区间更宽并跨0。

文本Student也有蒸馏提升均值，说明收益不能全部解释为视觉推理增强；其Teacher仍看图文，属于带额外信息的监督。

第一阶段Winoground日志中Group分数：原CLIP 9.00%、CE 2.333%、KD 3.250%、Jev 56.50%；KD−CE为+0.917个百分点，95%区间[−0.500,+2.417]。这轮未观察到明确的组合配对能力迁移，学生也远低于Teacher。

Winoground是配对排序诊断，不是E/N/C分类，不能把Group分数与Macro-F1放在同一列相减。旧CE/KD分别用P(E)打分，原CLIP用相似度，分数方式不同。该结果不能单独证明CLIP架构“不可能学会关系”，更不能冒充Stage2新模型的Winoground成绩。

本次已核实Winoground锁定的6个学生checkpoint属于第一阶段。完整实测预测包尚待找回归档；代码中的合成矩阵技术自检不是这项实验的结果。

### 学生确实更便宜 但保留的能力有限

P1在同一200条上，原始Jev Teacher Macro-F1为79.874%，第一阶段原始KD Student为64.113%；Stage2原始KD为63.500%。新旧学生都没有接近Teacher。原始Teacher成绩可作为同集参考；旧“校准Teacher”成绩对应旧校准参数，不能直接改名成Stage2新校准成绩。

P1实测同一T4、batch=1、同一50条输入每条重复3次：完整Student延迟中位数20.704ms，Jev为281.087ms，约13.58倍延迟比。Student包含预处理、CLIP和分类头；不是只测MLP。

这些是第一阶段固定部署模型与当时环境的实测记录，不能声称所有新checkpoint都重新测过。Student为FP32，Teacher底座为FP16；不包含磁盘读取与下载，显存报告是PyTorch allocated等口径，不是整卡占用。它支持限定条件下的成本优势，不支持“几乎不损失能力的压缩”。

## 8 论文应采用什么观点

建议主线：**任务适配Teacher向冻结CLIP学生的蒸馏，分类收益、概率质量和复杂能力保留是不同问题；完善对照后，必须分别评价它们。**

这是一种实证研究定位，不包装成新损失、新编码器或新校准算法。可以使用的工作标题是：

> 任务适配视觉语言教师向冻结CLIP学生蒸馏的实证研究：分类收益、校准取舍与迁移边界

论文可以提出的贡献：

1. 在可追溯的同任务设置中，比较CE、LS、KD及校准方案，并报告分类收益的不确定性。
2. 显示Teacher校准与简单Student后校准的取舍，避免把置信度改善等同于能力增强。
3. 结合单模态对照、Teacher同集能力、成本测量及配对诊断，说明轻量学生保留了什么、没有证实保留什么。

这些结论的“有多少新意”仍需靠相关工作逐项比较，不因为实验多或归档认真就自动成为创新。旧文献矩阵可以复用；不要把已有方法组合声称首次提出。

不能作为主张：稳定显著提高泛化、证明Teacher暗知识被迁移、证明修复CLIP推理、证明Teacher校准全面优越、证明蒸馏无效、证明方法等效。

也不应把文章简单叫作“失败报告”：概率质量与成本有实际观察，输入贡献也有证据。但这些正向观察不能替代尚未确认的分类优越性。
